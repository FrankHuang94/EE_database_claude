# Capstones

Four Term-7 projects show that the knowledge transfers to real engineering and diligence work. Each capstone has a brief, milestones, a rubric and a reference solution, and the reference solutions are verified like the rest of the curriculum.

| ID | Capstone | Deliverables | Prerequisites | Hours |
|---|---|---|---|---|
| C1 | **Analog:** design and verify a two-stage CMOS op-amp *or* a buck converter in ngspice against a specification | Design report, sizing calculations, ngspice netlists with automated spec checks, PVT corner results | Courses 20, 22 | ≈ 40 |
| C2 | **Digital:** take a small RISC-V-compatible or DSP block from RTL to layout with an open-source flow on Sky130 (Docker), *or* to a passing Verilator testbench plus a synthesis report | RTL, self-checking testbench, synthesis/timing/area reports, layout screenshots or GDS (full path) | Course 19 | ≈ 50 |
| C3 | **Embedded/system:** paper-and-simulation design of a wearable sensor node | Requirements, power budget, MCU selection, BLE link budget, battery-life model, firmware architecture | Courses 18, 21, 22 | ≈ 35 |
| C4 | **Practitioner:** technical diligence memo on a real public chip product, using only public information | 8–12 page memo: technology assessment, claim validation, risks, questions for management | Course 28 | ≈ 35 |

Briefs, rubrics and reference solutions are built in Phase 3.
