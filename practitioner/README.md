# Practitioner Layer

This is material for using engineering knowledge in M&A, venture and strategy work. Built in Phase 3, it draws on the "Practitioner lens" section of every chapter.

| Folder / file | Contents |
|---|---|
| `playbooks/` | Diligence playbooks by domain (digital/CPU, AI accelerator, analog/mixed-signal, RF, power, memory, interconnect/optics, packaging, embedded) |
| `question-banks/` | Questions to ask engineering leaders, with what strong vs evasive answers sound like |
| `case-studies/` | 10–15 real engineering decisions reconstructed from public sources (node choices, chiplet vs monolithic, build vs buy) |
| `scenarios/` | 25+ conversation scenarios written as dialogues with annotated debriefs (see Course 28) |
| `translation-table.md` | Business ↔ engineering metric translation |

Every chapter already includes a **Marketing vs Reality** box and 3–6 questions for engineering leaders; this folder consolidates and extends them.
