# Term Checkpoints

At the end of each term there is an FE-style checkpoint exam: 40–60 multiple-choice and numeric-entry questions covering the [NCEES FE Electrical & Computer](../reference/research-log.md#r-001--ncees-fe-electrical-and-computer-specification) knowledge areas taught so far. Each question comes with a full explanation, and every numerical answer is machine-verified like the rest of the curriculum.

**How to take one:**

- **Time:** about 3 minutes per question, which matches the FE pace (110 questions in 5 h 20 min).
- **Materials:** use only an FE-approved calculator and the *NCEES FE Reference Handbook* (free PDF from NCEES). Practicing with the handbook is part of the preparation.
- **Scoring:** score each knowledge area separately; aim for ≥ 70% in every area.
- **Follow-up:** add every miss to your error log and re-solve it a week later.
